# Aditya's Tech Report — 3 Oct 2026

DeepSeek put its agent harness on the desktop the same day Black Forest Labs shipped box-locked image edits, a cheap Stratego agent beat the long-time world number one, and Cloudflare opened MCP Server Portals to every plan.

## 1. DeepSeek Harness Desktop is in public preview for macOS and Windows

**Tag:** launch
**Why it matters.** A frontier lab's agent harness is now a signed desktop app, not only a terminal you clone.

DeepSeek's harness page is serving a public preview that installs as a desktop app on Windows and macOS, with a web UI via `npx @deepseek-ai/dsh web`. The architecture is Cordis, "everything is a plugin": file work, coding, research, and scheduled jobs are plugins, and Creator mode can add one. Source is at `deepseek-ai/deepseek-harness`. The HN thread, 379 points and about 200 comments overnight, says the desktop build has telemetry on by default, disableable in `cordis.patch.yml`, and that the web path does not phone home for local models. It also says the app can point at DeepSeek's API or another provider, including local Qwen-class models. Treat the ranking on frontierharness.org as a snapshot, not a bake-off.

Sources: [DeepSeek](https://www.deepseek.com/en/harness/) · [GitHub](https://github.com/deepseek-ai/deepseek-harness) · [HN](https://news.ycombinator.com/item?id=49929489)

## 2. Black Forest Labs ships FLUX 3 Image with box-locked edits

**Tag:** launch
**Why it matters.** The edit path claims to leave pixels outside a box numerically untouched, which is the failure mode in agent image pipelines.

Black Forest Labs put FLUX 3 Image on its API and playground on 2 October, the image arm of the FLUX 3 family that already had video. Users place elements with bounding boxes, pass up to ten reference images, and generate at native 2K or 4K. The company says a later edit changes only the selected region. API use is 50 percent off through 8 October; one report puts the discounted 768px price at $0.0205 an image, which the launch post itself does not list. Commercial weights are a license, not a download. Open weights are "coming weeks," with no date. The bit-identical claim is the vendor's until someone diffs the untouched region.

## 3. Ataraxos beat Stratego's long-time number one on 16 GPUs

**Tag:** news
**Why it matters.** Imperfect-information play just moved on a training bill a lab can expense, not a DeepMind-scale cluster.

A Nature paper from Carnegie Mellon, MIT, NYU, and Stanford, covered by Ars on 1 October and still on the HN front page, introduces Ataraxos. It beat Pim Niemeijer — four world titles, 600 weeks at number one — 15 games to one, with four draws. At the 2025 world championship it won 38 of 40. Training was 16 GPUs for a week, plus four GPUs for four days on a belief model that samples hidden setups instead of enumerating them. The authors put DeepNash, the prior Stratego system, at an estimated $3 million to $4.5 million; one summary of the paper puts Ataraxos under $8,000. The same recipe also beat bots at Hanabi and dou dizhu. Farina's caveat stands: a perfect strategy can still lose a randomized setup, and the system cannot explain a move.

## 4. Redis's author ships ds4, a local engine for DeepSeek, Qwen, and GLM

**Tag:** launch
**Why it matters.** The local path for the models people are actually swapping in is no longer a generic GGUF loader.

Salvatore Sanfilippo (antirez) published DwarfStar 4 at dwarfstar.sh. ds4 runs DeepSeek V4 Flash, DeepSeek V4.1, Qwen, and GLM with asymmetric 2-bit quantization on routed experts, and it does not load generic GGUF. CLI, HTTP, and a native agent share one model state. The KV cache can be written to SSD and resumed by prompt hash. Backends named on the site are macOS Metal and Linux CUDA. HN had it at about 160 points this morning. The license line on the site is thin; the repo is the artifact. This is a runtime for a short model list, not a llama.cpp replacement.

## 5. A Wagtail maintainer spent September on GLM 5.3 Flash and burned the budget anyway

**Tag:** take
**Why it matters.** The open-model swap works until one prototype picks the expensive model overnight.

Thibaud Colas, on the Wagtail core team, posted on 2 October after trying to spend September only on GLM 5.3 Flash. Half the month stayed on that model, about $68 and 4 kWh by his AgentsView numbers. The other half did not. A prototype on the wrong model spent 450 million tokens, about $150 and 5 kWh, almost overnight. Of 2 billion tokens, 1 billion landed on the target model. The post is a failure note with a working MCP demo, not a benchmark. The useful number is the overnight miss: seat-level budgets did not catch a single run.

## 6. Cloudflare's enterprise-for-all update makes MCP Server Portals generally available

**Tag:** shift
**Why it matters.** The gateway in front of MCP servers is no longer an enterprise SKU.

Cloudflare's 2 October update on its "enterprise for all" pledge opens Logpush (pay-as-you-go on Free, Pro, and Business), custom dashboards, wider RBAC, SCIM group sync, and higher limits on Workers, Containers, Browser Run, and AI Search. The same list marks MCP Server Portals generally available. That is the product change for agent builders: a portal in front of remote MCP servers, on plans that previously did not get the enterprise control plane. The post is a packaging change, not a new protocol. What it does not say is whether a portal can enforce a per-tool policy the customer's IdP already has.

Sources: [Cloudflare](https://blog.cloudflare.com/enterprise-for-all-update/) · [HN](https://news.ycombinator.com/item?id=49940152)

## 7. Amazon puts $1 billion over five years into datacenter host towns

**Tag:** news
**Why it matters.** The AI buildout's local veto just got a priced response, not a new chip.

The Register reported on 2 October that Amazon will spend $1 billion over five years on education, job training, local infrastructure, and sustainability in communities that host its datacenters. The framing is opposition and moratorium risk. The article notes what the pledge does not price: water for generation, rate impact, and generator air quality. This is not an AI product announcement. It is the community line item under the same buildout. No customer list and no split between AWS and other Amazon sites.

## 8. ChatGPT Sites is the argument on HN, not a launch

**Tag:** shift
**Why it matters.** The lab-hosted app is now a 220-comment fight about lock-in, and the feature itself is older than the thread.

OpenAI's Sites page — build and host a site, app, or game from a chat, on Plus, Pro, Business, Enterprise, and Edu during public beta — hit HN overnight at about 218 points and 220 comments. Commenters say they have had it for weeks, including inside Codex, so this is not a 2 October ship. Hosting is on `.chatgpt.site`, with custom-domain mapping documented and export for self-hosting. No CPU or memory cap is published. The thread's useful split is the one YC is also asking about: an agent can make the tool in an afternoon, and the share path is still the lab's domain or a real deploy. Abuse (miners, honeypots) is the open question, because the host is free.

## Buildable pain points

Three problems in current AI agent services that a small SaaS could take. Not a recap of the news items above.

### 1. The on-call cannot enter the agent run a teammate started

**Who.** VP Engineering at a 40–300 person company. The budget sits with the person who already signs Cursor Teams.
**What's broken.** A cloud agent has been on a migration for six hours. The author is offline. The on-call can see the PR. They cannot open the live run, redirect a tool call, or hand it to someone else without the author's laptop.
**Paying today.** X is paying Cursor Teams: Standard at $40 per seat per month, or Premium at $120 for 5x included usage. Cloud Agents are on Teams, including the automatic CI-fix on PRs they open.
**Y today.** Cursor Cloud Agents were bought to run coding tasks off the laptop, in an isolated VM, and to attach screenshots and logs to the PR. Team admins can list and fetch transcripts for runs in repos they already can access. Non-admins see only runs they started. Skills synced from `~/.cursor/skills/` stay private to that user. MCP OAuth is per-user, even on a team-shared server. The closest feature is the admin transcript fetch. It stops at a finished log: there is no documented way for a second person to join a live run and change the next tool call.
**SaaS wedge.** A drop-in on an existing cloud-agent run: watch, comment, take over, hand back, keyed to the run id Cursor already has. Ninety days is a client on the Cloud Agents API plus an approval on shell and write, not a new harness.
**Conversion test.** Attach, and unlock. They will not rip out Cursor. They will add the drop-in on the seat line they already defend, because a stuck six-hour run is already a sprint slip, and they will not buy more unattended seats until someone other than the author can enter the run. YC's Fall 2026 Multiplayer AI request, still being written up on 2 October, asks for this exact handoff.
**Why incumbents leave it.** Cursor's own access table says a non-admin cannot view another member's chat. A product that puts the on-call inside that chat fights the privacy default, and per-user MCP OAuth means a takeover also needs a token the second person does not have.

Sources: [YC RFS, Multiplayer AI](https://www.ycombinator.com/rfs) · [RFS write-up, 2 Oct](https://imasters.com/tecnologia/y-combinator-updates-its-rfs-list-and-points-ai-outside-the-screen) · [Cursor Cloud Agents](https://cursor.com/docs/cloud-agent/capabilities) · [Cursor Teams pricing](https://cursor.com/docs/account/teams/pricing)

### 2. The agent-built tool has no share path on the company's IdP

**Who.** Head of operations at a 20–200 person company who already pays for internal tools. The budget sits with the person who signs Vercel and the identity provider.
**What's broken.** An agent builds a tracker in an afternoon. Sharing it with a nontechnical teammate means an OpenAI subdomain, a shared password, or a Vercel project that needs a git repo and a team membership. The tool dies, or it lives where IT cannot revoke it.
**Paying today.** X is paying Vercel Pro. Password Protection is $20 per month per protected project on Pro, not available on Hobby, and included at team level on Enterprise. Vercel Authentication is on every plan at no extra charge. Okta, or whatever IdP they already have, is a separate invoice.
**Y today.** Vercel was bought to host projects. Vercel Authentication lets someone with a personal account on the team open a preview or production deploy. Password Protection is a shared secret, billed per project. Neither maps an arbitrary agent artifact to an Okta group, and neither accepts a chat export as the deploy unit. ChatGPT Sites, the path in item 8, hosts on `.chatgpt.site` and can map a custom domain; the login is still OpenAI's plan, not the customer's IdP. The closest feature is Vercel Authentication. It stops at "already on this Vercel team."
**SaaS wedge.** A share front for one-off agent artifacts: customer's IdP group, revoke from the IdP, no new cloud account for the recipient. Ninety days is a proxy in front of a Sites export or a static bundle, not a new PaaS.
**Conversion test.** Attach. They stay on Vercel for anything that is a real project. The wedge sits on the identity line they already defend, because the alternative is a tool on a lab domain that IT cannot disable, and YC's Fall 2026 request for a cloud for small software names auth and sharing with nontechnical users as the hard part.
**Why incumbents leave it.** Vercel sells projects and seats. A product whose job is that this tracker never becomes a project fights that SKU. OpenAI's Sites job is to keep the app on `chatgpt.site`.

Sources: [YC RFS, A Cloud for Small Software](https://www.ycombinator.com/rfs) · [Vercel access control](https://vercel.com/docs/security/access-control) · [ChatGPT Sites](https://chatgpt.com/features/sites/)

### 3. The seat budget does not stop the run that spends $150 overnight

**Who.** VP Engineering who signs the coding-agent invoice. The scene is a small team that already let agents run unattended.
**What's broken.** The Wagtail post on 2 October is the scene: the month was supposed to stay on a cheap open model, and one prototype spent 450 million tokens, about $150, almost overnight. The monthly seat pool still had room. The alert, if it fired, fired after the run.
**Paying today.** X is paying Cursor Teams, Standard or Premium. Included usage is per seat and does not transfer. Team-wide monthly spending limits are on the dashboard. Per-member spend limits are Enterprise only. Dollar alerts go to Slack or email.
**Y today.** Cursor's June 2026 pricing change was bought for predictability: a larger included pool, a Premium seat at 5x usage, and alerts before a billing surprise. The team monthly limit stops further usage after the cap. It does not attach a dollar or token ceiling to one cloud-agent run, and it does not kill that run when the ceiling trips. The closest feature is the alert. It stops at notification. The $150 in the Wagtail note would have cleared a team cap that was set for the month, not for the prototype.
**SaaS wedge.** A task budget in front of the agent run: max dollars, hard stop, receipt to the admin channel with the run id. Ninety days is a proxy on the run webhook, not a new billing system.
**Conversion test.** Attach. They stay on Cursor for the seats. The wedge sits on the usage line they already defend, because the overnight miss was inside the monthly limit, and they will not approve more unattended runs until a single task can be capped. Alerts do not unlock that.
**Why incumbents leave it.** Cursor's contract is seat pools and a monthly team cap. A per-task kill implies the agent should have been stopped, which is an argument against the overage the seat is priced to allow.
